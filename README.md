# Kindle Help App WAF Loader
Loads wafs by exploiting the help app. Must be rooted first, it is used as a waf tester. May not be great

Just download source code and put it on your kindle. WAFs are loaded through the /waf folder in the root of the usb drive. A test WAF is included.

Note: It doesnt support more than one WAF. 

Basically, it mounts the WAF folder where the help app WAF is and then launches the help app, then when the help app closes it unmounts the custom WAF folder.
